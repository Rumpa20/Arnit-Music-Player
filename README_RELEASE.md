# Arnit Music Player

Android music player project.

- Application ID: `online.arnitcreation.musicplayer`
- Version: `1.7.1` (versionCode 14)
- Minimum Android: API 26
- Target Android: API 35
- Build: Gradle / Kotlin / Jetpack Compose / AndroidX Media3
- Contact: abhijitdas021984@gmail.com

## Features

- Local audio library and folder browsing
- Online audio playback
- Favorites, playlists, queue and recently played
- Player screen, media controls, equalizer and sleep timer
- Lyrics editor and user-triggered LRCLIB online lyrics lookup
- Local backup export and restore
- Light/dark appearance and selectable backgrounds

## Build

Open the project in Android Studio or a compatible Android Gradle environment and run `:app:assembleDebug`. A release build should be produced only after reviewing signing, dependencies, permissions, and reproducibility.
